# A Wildlife Camera Trap Dataset for Vulnerable Houbara Bustard Adult, Chick, and Egg Detection

This repository accompanies the paper **"A Wildlife Camera Trap Dataset for Vulnerable Houbara Bustard Adult, Chick, and Egg Detection"**, published in the **2025 IEEE International Conference on Image Processing Workshops (ICIPW)**.

The work introduces a wildlife camera-trap dataset designed for automated monitoring of the vulnerable Houbara bustard. The dataset focuses on detecting three biologically important classes associated with breeding and reproductive monitoring:

- Houbara bustard adults
- Houbara bustard chicks
- Houbara bustard eggs

The dataset contains **10,394 camera-trap images** and **23,387 manually annotated object instances**, with bounding-box annotations for adult, chick, and egg detection. It is intended to support research in wildlife monitoring, nest surveillance, conservation technology, and deep-learning-based object detection for ecological applications.

Several state-of-the-art object detection models were evaluated on this dataset, with **YOLOv12** achieving the best overall performance across multiple evaluation metrics.

## Abstract

AI tools are increasingly employed in wildlife conservation to monitor animal populations and detect anthropogenic threats. Although various wild animal image datasets exist for training deep learning algorithms in species recognition, few resources focus on bird classification, particularly for monitoring reproductive success at nests. To address this gap, this work introduces a new dataset concentrating on the Houbara bustard, a bird of both ecological and cultural significance, comprising 10,394 images and 23,387 object instances, including Houbara adults, chicks, and eggs, each manually annotated with bounding boxes. Several state-of-the-art object detection techniques were assessed on this dataset, with YOLOv12 demonstrating superior performance across multiple evaluation metrics. This dataset provides a valuable resource for researchers and conservation practitioners, enhancing the capability for automated wildlife monitoring and conservation efforts.
